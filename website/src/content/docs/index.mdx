```bash
npx create-expo-boilerplate@latest my-app
```

Answer a few questions, or press Enter to take the defaults. The CLI writes an app with only the stack you chose, installs dependencies and makes the first git commit.

## Pick your stack

| Choice | Options (default first) |
| --- | --- |
| Navigation | Expo Router (typed routes) · React Navigation |
| State management | Zustand · Redux Toolkit with Thunk or Saga |
| Styling | Unistyles 3 · React Native StyleSheet · Tailwind (Uniwind) |
| Language | TypeScript · JavaScript |
| Tooling | ESLint and Husky, each on or off |
| Package manager | yarn · npm · pnpm · bun |

That's 144 combinations. A test script generates each one and checks that it type-checks, lints, passes its tests and has no leftover code from the options you didn't pick, and CI runs it on every change.

## Built to scale

Code is organised by feature (`src/features/auth`, `src/features/posts`, …). Each feature exposes a small public API, and screens talk to state only through hooks like `useLogin()` and `useIsLoggedIn()`. That's why the CLI can swap Zustand for Redux, or Expo Router for React Navigation, without touching a single screen.
